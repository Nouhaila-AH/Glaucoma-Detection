# Traditional Chatbot Project

**📌 Overview**

This is a rule-based chatbot project built using Python. The chatbot processes user inputs based on predefined intents stored in a JSON file. It utilizes natural language processing (NLP) techniques to understand and respond to user queries.

**🚀 Features**

📁 Uses an intents.json file for predefined responses

🧠 Machine learning-based training with NLP techniques

🔄 Supports conversational interactions

📌 Simple and lightweight implementation
